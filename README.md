One original line of fortune-cookie wisdom for a software developer.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
Your code will outlive your comments; write both as if a tired stranger must fix them at 3 a.m.
```
